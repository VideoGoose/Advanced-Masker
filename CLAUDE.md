# Advanced Masker — disguise Designer plugin

Pen-tool masking inside Designer: mask layers (on/off, modes, feather, expansion, opacity, invert,
lock), canvas sized from a mapping, live output on a Web layer, PNG/TIF export into
`objects/VideoFile/masks/` or `objects/DxTexture/masks/`. No bridge: everything runs from the
plugin folder. Built on the same Designer plumbing as the sibling Test Pattern+ project
(`../test-pattern-plus/CLAUDE.md` has the hard-won sandbox notes; they apply here too).

Machine-specific notes (install path, Designer port) live in `CLAUDE.local.md` (git-ignored).
Keep names, user paths and e-mail addresses out of tracked files.

## Working rules

- Keep the plugin simple. **No keyboard shortcuts except the arrow keys** (nudge selected points;
  Shift bigger / Ctrl smaller steps, sizes in Settings). Shift / Ctrl as drag/click/arrow modifiers
  are fine (sliders: Shift coarse, Ctrl slow + fine). Enter / Escape only inside dialogs.
- Every control gets a `title`; the window moves it to `data-tip` and shows its own tooltip after
  `prefs.tipDelay` ms (Designer's browser can't be trusted with native ones).
- Don't name other vendors' products in code, UI text or docs.
- Edit `src/` only; `dist/` is generated by `python build.py`.
- Bump `VERSION` in `build.py` on every change you install and tell the user the number (0.1.x).
- Install: `python build.py --install "<Designer project>\plugins"`; the user must close and reopen
  the plugin window. `masks/` (saved mask sets) is never touched by an install.
- Test: `npm install`, `npx playwright install chromium` once, then `python tests/run_tests.py`.
  Look at `tests/out/*.png` after visual changes.
- Saved data must stay readable: Web layer URLs (`#name=…&d=<base64url JSON>`, short keys in
  `AMask.pack`) and mask set files (`{plugin, version, name, saved, doc}`). Never rename or reuse
  a packed key or a `MODES` index; append new ones.

## Model (src/mask.js)

Document `{name, w, h, mapping, style 0 luma | 1 alpha, invertAll, masks[]}`; mask
`{id, name, on, locked, closed, mode, inv, feather, fpos 0 on path | 1 inside | 2 outside, expand, opacity, colour, pts[]}`; point
`{x, y, ix, iy, ox, oy, s}` in document pixels, handles relative to the point.
Render: per mask, fill the path (+ stroke for expansion, destination-out stroke for negative),
edge first moved by ∓feather/2 for Inside/Outside, blur with sigma = feather / 4 (canvas filter, JS box blur fallback) on a padded canvas so edges
don't darken, × opacity, invert, combine top-down (Add sum, Subtract, Intersect multiply,
Lighten max, Darken min, Difference abs). First mask starts from empty for Add/Lighten/Difference,
full for the rest; no renderable mask = all white. Open paths and mode None draw nothing.
The editor renders only the visible part of the canvas at screen resolution.

## How it talks to Designer

Same as Test Pattern+: window served at `/projects/<p>/plugins/advanced-masker/`, API discovery
(`?director` → last good → same origin → 80/81/8080), `registermodule` as `gus_am`, `execute`
with double-encoded `returnValue`. New Web layer = separate calls `add_layer` (Size mode → Match
Mapping) → `make_bookmark` → `attach_bookmark` (fallback `set_url_field`) → `set_mapping` when the
canvas size came from a mapping. Web layers use 127.0.0.1 (zoom leak, see Test Pattern+ notes).

Mappings: `resourceManager.allResources(cls)` for each of `MAPPING_CLASSES` (`Projection`,
`DirectProjection`, `FeedProjection`, … names taken from Designer's own editors), de-duplicated.
Size = the mapping's own `resolution`-like attribute, else its single screen's resolution, else the
largest of its screens. **Unverified in Designer**: which attributes real mappings expose. Probe
(connection panel) dumps mapping attrs; pin them in `RES_ATTRS` / `SCREEN_LIST_ATTRS`.

Reference picture: `list_images()` walks objects/DxTexture + VideoFile, `read_image()` returns
base64 pieces (≤1 MB). Exports: `write_export(folder, name, b64, first)` builds the path itself
(only VideoFile / DxTexture, `masks` subfolder, .png/.tif names).

## Ideas not built

Variable-width feather points, auto-curved (tension) paths, keyframed / animated masks, mask
tracking, free-transform box (scale/rotate), per-mask motion blur.
